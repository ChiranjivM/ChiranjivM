## Projects

### Crypto Arbitrage Monitor

[View Project](https://github.com/ChiranjivM/crypto-arbitrage-monitor)

A cryptocurrency market monitoring system built to explore exchange APIs, financial data, and statistical analysis.

**Features:**
- Real-time exchange price monitoring
- Arbitrage spread analysis
- Fee-adjusted profit calculations
- Statistical anomaly detection using Z-scores
- Interactive Streamlit dashboard visualization

---

### Gesture Recognition AI *(Work in Progress)*

A computer vision project exploring real-time hand gesture recognition and interactive visual effects using webcam input.

**Features:**
- Real-time hand tracking
- Hand landmark detection using MediaPipe
- Custom gesture recognition logic
- Interactive visual effects and animations
- Real-time webcam processing with OpenCV
